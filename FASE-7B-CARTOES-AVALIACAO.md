# Avaliação dos cartões de Pequeno Grupo

Abaixo estão seis cartões de Pequenos Grupos, como apareceriam para um tutor ou coordenador.

Para cada cartão, responda quatro perguntas. **Não há resposta certa** — queremos saber o que o
cartão comunica a você, na primeira leitura.

1. A **posição parece plausível** diante do que você conhece desse PG?
2. Os **indicadores explicam adequadamente** a posição?
3. Existe alguma **informação importante que o cartão sugere erroneamente**?
4. Você **confiaria nesse indicador** para orientar uma conversa pastoral com o tutor?
