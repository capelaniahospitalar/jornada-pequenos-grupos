## A pergunta única desta fase

> ### Os cartões conseguem explicar corretamente o ranking e, ao mesmo tempo, revelar as fragilidades pastorais de cada PG?

O objetivo do IMD não é dizer *"você está em segundo"*. É permitir que o tutor diga:
**"entendi por que estamos em segundo — e entendi onde precisamos crescer."**

## Como usar este documento

**Leia cada cartão primeiro. Só depois leia a nota de contexto.** A pergunta é se o cartão comunica
sozinho. Para cada um, responda quatro perguntas:

1. **A posição parece plausível** diante do que conhecemos desse PG?
2. **Os indicadores explicam adequadamente** a posição?
3. Existe alguma **informação importante que o cartão sugere erroneamente**?
4. **Você confiaria nesse indicador** para orientar uma conversa pastoral com o tutor?

> **Regra de ouro:** o resultado não deve ser usado para "corrigir" o ranking, e sim para verificar
> se o modelo descreve a realidade **sem escondê-la**. Um cartão que revela a fragilidade de um PG
> bem colocado é um acerto do sistema, não um defeito.

**Nomenclatura em avaliação:** Alta ≥75% · Média 60–74% · Baixa 40–59% · Muito baixa <40% ·
Sem Evidência = 0. **Mesmos limiares homologados — mudou só o vocabulário.**

## A arquitetura que estes cartões materializam

| Camada | Papel | No cartão |
|---|---|---|
| **IMD** | **ordena** | nota + posição |
| **Capilaridade** | mostra a **proporção** alcançada | `Média — 71%` |
| **Alcance absoluto** | mostra **quantas pessoas** efetivamente caminharam | `5 de 7 participantes` |
| **Envolvimento · Missão · Profundidade** | apontam **onde o PG precisa crescer** | linhas seguintes |

Nenhuma dessas leituras tenta fazer sozinha o trabalho das outras. É isso que uma nota única não
conseguia entregar.

**Duas coisas que os cartões deliberadamente NÃO fazem:**
- não escondem a fragilidade de um PG bem colocado (cartão 2);
- não inventam uma nota para diferenciar dois PGs sem base de comparação (cartões 5 e 6) — a
  diferença aparece no contexto, nunca no cálculo.
